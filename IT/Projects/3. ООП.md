### Задание 1: Классы User и Order

> **Примечание**: Это самостоятельное задание для закрепления материала.

**Задача:**

Рядом с `Product` магазину нужны ещё два класса. Создай класс `User` (атрибуты `name`, `email`; метод `get_info()` возвращает строку `Пользователь: {name}, Email: {email}`) в файле `src/models/user.py` и класс `Order` (атрибуты `user`, `products`; метод `calculate_total()` возвращает сумму `get_total_price()` всех товаров заказа) в файле `src/models/order.py`. В `src/main.py` создай пользователя, два товара (ноутбук за 50000 в количестве 1 и мышь за 1500 в количестве 2), заказ из этих товаров и выведи `get_info()` пользователя и общую стоимость заказа.

**Начни с этого:**

PYTHON

Копировать

```python

# Файл src/models/order.py

# Файл src/main.py
```

### Задание 2: Валидация цены через @property

> **Примечание**: Это самостоятельное задание для закрепления материала.

**Задача:**

Создать в журнале `src/main.py` учебный класс `Product` с валидацией цены через `@property` - цена не может быть отрицательной. Это учебный класс: он перекрывает импортированный из `src/models/product.py` класс до конца секции урока, а сам файл `src/models/product.py` не трогаем.

**Начни с этого:**

PYTHON

Копировать

```python
# Практика: Задание 2 - Валидация цены через @property
class Product:
    def __init__(self, name, price):
        self.name = name
        # price должен проходить через setter
```
