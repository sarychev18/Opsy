В этом уроке мы начинаем работать над проектом **SFMShop** - интернет-магазином, над которым мы будем работать на протяжении всего курса.

**Структура уже есть в эталоне онбординга** (урок «Онбординг», кнопка «Скачать проект (.zip)» внизу страницы):

1. **Папка проекта** `SFMShop/` - корневая папка нашего проекта
2. **Файл `SFMShop/README.md`** - описание проекта (что это за состояние и как его запустить)
3. **Папка `SFMShop/src/`** - папка с исходным кодом; в ней уже лежит пустой `src/__init__.py` - он нужен с урока про модули, не удаляй его
4. **Файл `SFMShop/src/main.py`** - главный файл, где мы будем писать код; сейчас в нём только комментарий-заглушка и строка `print("SFMShop: окружение готово")` для контрольного запуска

**Как вести файл `src/main.py`:** открой его, удали заглушку и строку `print("SFMShop: окружение готово")` - с этого урока файл становится журналом курса. Каждый урок дописывает в конец файла свою секцию с заголовком `# УРОК N: …`, а каждое задание практики идёт внутри секции под своим заголовком `# Практика: Задание N - …`. Так же подписан эталон после каждого урока - по этим подписям сверяйся со своим файлом. Эталон предыдущего урока - это то, с чем твой файл совпадает перед новым уроком.

Если ведёшь проект сам, без эталонов, - создай папку `SFMShop/`, внутри папку `src/`, а в ней пустые файлы `__init__.py` и `main.py`.

**Важно**: В этом уроке мы будем писать весь код в файле `src/main.py`.
